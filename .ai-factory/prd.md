# ScoreClimb

## Platform
앱인토스 (Vite + React + TDS)

## One-liner
매일 미션을 수행하며 신용점수를 게임처럼 올리는 습관 트래커

## Problem
많은 사회초년생과 2030 유저가 신용점수 관리 방법을 몰라 방치하고, 개선 노력을 지속할 동기가 없어 점수가 정체된다

## Target Users
신용점수 관리가 필요한 20-30대 사회초년생 및 첫 대출/카드 이용자

## Core Features
1. 토스 신용점수 연동 현황 대시보드
2. 데일리 미션 체크리스트 (카드 사용률, 연체 방지 등)
3. 연속 출석 스트릭 및 배지 시스템
4. 점수 개선 시뮬레이션 (리워드 광고 게이팅)
5. 또래 평균 대비 내 점수 비교 리포트
6. 미션 알림 푸시

## Monetization
- Model: ads
- Estimated MRR: 월 약 58만원
- Reasoning: 매일 미션 체크 습관으로 DAU가 안정적으로 유지되고, 점수 개선 시뮬레이션 결과를 리워드 광고 뒤에 배치해 전환율을 높인다. 배너는 미션 목록 사이에 자연 배치
