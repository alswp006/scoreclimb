# ScoreClimb

앱인토스 (Vite + React + TDS) 매일 미션을 수행하며 신용점수를 게임처럼 올리는 습관 트래커 많은 사회초년생과 2030 유저가 신용점수 관리 방법을 몰라 방치하고, 개선 노력을 지속할 동기가 없어 점수가 정체된다

## Tech Stack

- React 18.0.0
- TypeScript
- Vitest
